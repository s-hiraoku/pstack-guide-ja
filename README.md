# pstack 日本語ガイド

このリポジトリには、役割の違う2つの日本語資料があります。混ぜて読まないでください。

## 実践入門

このリポジトリ独自の入門です。Cursorへの導入から、検証スキル、設計、レビュー、PR、Cloud Agents、長時間運用までを、練習プロジェクト付きで解説します。

- [HTML版](pstack-guide-ja.html)
- [Markdown版](pstack-guide-ja.md)
- [練習用プロジェクト](pstack-first-project.zip)

調査基準日は2026年9月12日です。pstack公式リポジトリのコミット `889ec4b68fa5aab0e867dad71ec3fdf386ae48f3`、プラグイン版 `0.15.2` を基準にしています。

実践入門は、Lauren Tan（@poteto）が公開している [公式pstack](https://github.com/cursor/plugins/tree/main/pstack#readme) に基づいています。

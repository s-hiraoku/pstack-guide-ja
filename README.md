# pstack実践入門（日本語ガイド）

pstackを、Cursorへの導入から、検証スキル、設計、レビュー、PR、Cloud Agents、長時間運用まで解説する日本語ガイドです。

## 読む

- [HTML版](pstack-guide-ja.html)
- [Markdown版](pstack-guide-ja.md)
- [練習用プロジェクト](pstack-first-project.zip)

調査基準日は2026年9月12日です。pstack公式リポジトリのコミット `889ec4b68fa5aab0e867dad71ec3fdf386ae48f3`、プラグイン版 `0.15.2` を基準にしています。

## 対象

本ガイドは、Lauren Tan（@poteto）が公開している [公式pstack](https://github.com/cursor/plugins/tree/main/pstack#readme) に基づいています。

練習用プロジェクトは本ガイド用に作成した教材で、pstack公式の配布物ではありません。
